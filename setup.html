Step 2 — Snipcart (cart & payments)

  1. Create a free account at snipcart.com
  2. Copy your Test API key from Dashboard → Account → API keys
  3. Copy js/config.local.example.js → js/config.local.js
  4. Paste the key into snipcartApiKey and push to GitHub (or edit on GitHub)
  5. In Snipcart → Domains, add your live site URL
Open Snipcart

Step 3 — Printful (print & ship)

  1. Create account at printful.com
  2. Create each product with Bombshell artwork (see js/products.js for names & prices)
  3. In Snipcart → Apps → Printful → connect accounts
  4. Map each product slug to Printful variant (see printful-product-map.json)
Open Printful

Step 4 — Test order

Use Snipcart test mode, add a hoodie to cart, checkout with test card, confirm order appears in Printful with customer shipping address.

Go to Shop

Step 5 — Go live

Switch Snipcart to Live API key in config.local.js. Connect Stripe in Snipcart for payouts. Optional: point bombshellbossbabes.com DNS to GitHub Pages.

Membership packages (Stripe)
