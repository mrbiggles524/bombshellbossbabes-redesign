Step 2 — Snipcart (cart & payments)

  1. Create a free account at snipcart.com
  2. Copy your Test API key from Dashboard → Account → API keys
  3. Copy js/config.local.example.js → js/config.local.js
  4. Paste the key into snipcartApiKey and push to GitHub (or edit on GitHub)
  5. In Snipcart → Domains, add your live site URL
Open Snipcart

Step 3 — Printful (print & ship)

Skip Printful’s “Connect Shopify/Etsy” step — your store is already Snipcart + GitHub Pages.

  1. Account at printful.com (you’re here ✓)
  2. Pilot first: create the Hoodie in Product catalog → upload artwork → save to My products
  3. Add billing method (Printful charges you per fulfilled order)
  4. When orders arrive: Snipcart Dashboard → copy address → Printful → Create order (manual, no code)
  5. Later: automate with Snipcart webhooks + Printful API (optional)
