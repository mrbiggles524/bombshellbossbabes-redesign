What to ignore on the Printful home screen

Step 2 “Connect your store” (Shopify, Etsy, WooCommerce) is not for this site. Your storefront is already live on GitHub Pages + Snipcart.

Instead: Stores → Add store → Manual orders / API (or just design products — billing is what matters for fulfillment).

Phase 2 — Billing (~5 min)

Printful charges you per order (print cost + ship). Customer already paid via Snipcart.

  1. Printful → Billing → Billing methods → add card
  2. Settings → Stores → set selling region (US / worldwide)
Add billing method

Phase 3 — Fulfill orders

Fastest (no code): When a Snipcart order comes in → Printful → Orders → Create order → pick your product → paste customer ship address from Snipcart.

Automated (later): Snipcart webhook → small server → Printful API. Static GitHub Pages can’t run that in-browser; we can add a Cloudflare Worker or Vercel function when you’re ready.
